A private AI assistant
with a dedicated workspace.

OpenClaw Assistant is an individually operated automation setup. It helps its owner review incoming messages, track follow-ups, keep a calendar, and organize working documents using a dedicated Google account.

Gmail — read onlyGoogle TasksGoogle CalendarGoogle DriveGoogle Docs & Sheets
Private use only. This is not a public sign-up service, does not provide access to other users' accounts, and is not an official product or endorsement of OpenClaw, GitHub, or Google. The site only explains this personal OAuth application.

What the assistant does

Review inbox changes

Read messages received in a dedicated mailbox, classify urgency, and prepare short summaries. Gmail access uses a read-only OAuth scope.

Track commitments

Create and update personal tasks, deadlines, and confirmed events in Google Tasks and Calendar.

Organize working files

Use the dedicated Google Drive account for working documents, notes, and structured Sheets.

Human-directed actions

External communications, file sharing, and other consequential changes are intended to require owner approval.

Privacy by design

The Google account and OAuth configuration are controlled by the individual operator. No OAuth credentials or private mailbox contents are hosted on this public website. Selected messages may be processed by third-party AI inference services to produce summaries or suggested actions, as explained in the Privacy Policy.

About this site

This is a static public information page for a private OAuth integration. It does not offer log-in, account registration, or a user-facing Google data collection form. For general questions, use the public repository issue tracker; do not post sensitive data there.
